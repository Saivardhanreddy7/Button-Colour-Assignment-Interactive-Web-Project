# Button Colour Assignment

An interactive web project built using **HTML, CSS, and JavaScript**. The project contains nine buttons, and each button is assigned a different colour when clicked. After a button receives a colour, it becomes disabled to prevent repeated clicks.

## Features

* 9 interactive buttons
* Assigns colors sequentially when buttons are clicked
* Disables the clicked button
* Simple and responsive grid layout
* Clean and user-friendly interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How It Works

1. Open the `index.html` file in a web browser.
2. Click any button.
3. The button gets the next available color.
4. The button becomes disabled.
5. Continue clicking the remaining buttons to assign all colors.

## Color Sequence

`Red → Blue → Green → Orange → Purple → Pink → Yellow → Cyan → Brown`
